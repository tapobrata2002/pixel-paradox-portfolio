# 🎬 Pixel Paradox — Creative Portfolio

### Frames. Motion. Stories.

Where frames find meaning, motion creates emotion, and stories come to life.

**Pixel Paradox** is a creative portfolio website built to showcase visual storytelling through video editing, motion graphics, and filmmaking. It brings creative work together in a dedicated digital space, presenting projects through an engaging and visually driven web experience.

Built with React and powered by Vite, the portfolio combines modern frontend development with a distinctive creative identity.

🌐 **Live Website:** [https://pixel-paradox-portfolio.vercel.app/](https://pixel-paradox-portfolio.vercel.app/)

📂 **GitHub Repository:** [https://github.com/tapobrata2002/pixel-paradox-portfolio](https://github.com/tapobrata2002/pixel-paradox-portfolio)

---

## 🚀 Features

- 🎨 **Creative Portfolio Design** — A distinctive visual identity designed around the Pixel Paradox brand.
- 🎬 **Video Editing Showcase** — Dedicated portfolio sections for presenting different video editing projects.
- ✨ **Motion Graphics Showcase** — A dedicated space to explore motion graphics and animation work.
- 🎥 **Filmmaking Portfolio** — Showcases creative filmmaking and visual storytelling projects.
- 📂 **Dynamic Project Organization** — Project information is maintained in a centralized data structure.
- 🔀 **Category-Based Navigation** — Navigate between different creative disciplines using React Router.
- 📱 **Responsive Interface** — Designed to provide an accessible browsing experience across different screen sizes.
- ⚡ **Fast Performance** — Powered by Vite for a fast development experience and optimized production builds.
- 🧩 **Reusable Components** — Structured React components for maintainable and scalable development.

## ⚙️ How It Works

### 1️⃣ Application Initialization

- React initializes the application through the main entry point.
- Vite provides the development environment and production build system.
- The main application component manages the overall website structure.

### 2️⃣ Navigation & Routing

- React Router DOM handles client-side navigation.
- Visitors can navigate between different portfolio categories.
- Category-based pages organize creative projects into dedicated sections.

### 3️⃣ Project Management

- Project information is maintained in a centralized JavaScript data file.
- Each project contains structured information such as its title, category, video link, aspect ratio, and description.
- This approach makes adding and updating portfolio projects easier.

### 4️⃣ Portfolio Presentation

- Projects are presented through dedicated portfolio sections.
- Visitors can explore different creative disciplines and view the associated video work.
- The interface is designed around a consistent visual identity.

### 5️⃣ Deployment

- The application is built using Vite.
- Production-ready files are generated through the build process.
- The website is deployed on Vercel.

## ▶️ Installation & Setup

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm (Node Package Manager)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/tapobrata2002/pixel-paradox-portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd pixel-paradox-portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local development URL displayed in your terminal to view the website.

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```

### 7. Run ESLint

```bash
npm run lint
```
